## Projects

### [MediaClip](https://github.com/mata-ken/MediaClip)
> A modern clipboard manager for macOS — text, images & videos.

A [Clipy](https://clipy-app.com/) alternative with media support. Saves clipboard history including screenshots and screen recordings, with snippet management and global shortcut access.

`Swift` `SwiftUI` `AppKit` `macOS`

---

### [ManualCapture](https://github.com/mata-ken/ManualCapture)
> Auto-capture steps as you work — create manuals without effort.

A [Tango](https://www.tango.us/) alternative that runs natively on Mac. Records clicks and keyboard actions with automatic screenshots, annotation tools, AI-generated descriptions, and PDF/HTML export.

`Electron` `React` `TypeScript` `Objective-C++` `Tailwind CSS`
