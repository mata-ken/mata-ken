# Logic Pro プラグイン総点検ツール

買ったプラグインが Mac のどこにあるのか、どれを使っていてどれを使っていないのか、それぞれ何をするツールなのかを、**1回実行するだけで全部調べてレポートにする**ツールです。

> ⚠️ このツールは **読み取りだけ** を行います。ファイルの移動・削除は一切しません。
> 整理用のスクリプトは「作るだけ」なので、中身を確認してから自分で実行するか決められます。

---

## 調べる内容

| # | 内容 | 調べる場所 |
|---|---|---|
| 1 | インストール済みプラグイン（AU / VST / VST3 / CLAP / AAX）の場所・バージョン・サイズ・Apple Silicon 対応 | `/Library/Audio/Plug-Ins/…`、`~/Library/Audio/Plug-Ins/…`、`/Library/Application Support/Avid/…` |
| 2 | **使用履歴**：過去の Logic プロジェクト（`.logicx`）を1つずつ読み、どのプラグインを・いつ・何曲で使ったか | ミュージック・書類・デスクトップ・iCloud Drive・Dropbox・外付けドライブ ＋ Spotlight 検索 |
| 3 | **役割の自動分類**：ドラム / ベース / ギター / ピアノ / シンセ / オーケストラ / ボーカル / EQ / コンプ / リバーブ / マスタリング など 22 分類と、それぞれの機能の説明 | 製品名・メーカー名・プラグインの種類から判定（有名プラグイン数百種類に対応） |
| 4 | 音源ライブラリ（Kontakt・Spectrasonics・Spitfire・EastWest・Toontrack など）の場所と容量、重複 | 内蔵ディスク・外付けドライブ・Native Instruments の登録情報 |
| 5 | ダウンロードフォルダなどに散らばったインストーラー（`.dmg` / `.pkg` / `.zip`） | ダウンロード・デスクトップ・書類 など |
| 6 | 要注意ポイント：Intel 専用（Rosetta 必要）、AU版がない（Logicで使えない）、AAX（Pro Tools 専用）、リンク切れの音源 | — |

## 使い方（Mac で）

### 1. ダウンロード

GitHub のこのフォルダ（`logic-plugin-audit`）を Mac にダウンロードします。
いちばん簡単なのは、リポジトリのページで **Code → Download ZIP** を押して展開する方法です。

### 2. 実行

**方法A：ダブルクリック**

`run_audit.command` をダブルクリックします。

- 「開発元を確認できないため開けません」と出たら → **右クリック → 開く → 開く**
- 「"ターミナル"が"書類"フォルダ内のファイルにアクセスしようとしています」などと聞かれたら → **許可**（プロジェクトを探すために必要です）
- 「コマンドライン・デベロッパ・ツールが必要です」と出たら → **インストール**を押して完了後にもう一度ダブルクリック

**方法B：ターミナル**

```bash
cd ~/Downloads/logic-plugin-audit   # 展開した場所
python3 plugin_audit.py
```

### 3. 結果を見る

終わると、デスクトップに `Logicプラグイン点検_日付` フォルダができて、レポートが自動でブラウザに開きます。

| ファイル | 中身 |
|---|---|
| `report.html` | **メインのレポート**（サマリー / 役割別 / 一覧 / 未使用 / 音源ライブラリ / インストーラー / プロジェクト / 整理プラン / 要注意） |
| `summary.md` | 数字だけのまとめ |
| `plugins.csv` ほか | Excel / Numbers で開ける一覧表 |
| `logic_categories.md` | Logic のプラグインマネージャで作るフォルダと、そこに入れるプラグインの対応表 |
| `organize_installers.sh` / `undo_installers.sh` | インストーラーをメーカー別に集める／元に戻すスクリプト |
| `quarantine_plugins.sh` / `restore_plugins.sh` | 使っていないプラグインを退避する／元に戻すスクリプト（初期状態では全行無効） |
| `category_overrides.csv` | 分類の手直し用 |
| `audit.json` | 全データ（Claude に渡すと、さらに詳しい分析や整理の提案ができます） |

## ⏱ 所要時間の目安

### ツールの実行時間（放っておくだけ）

| 環境 | 目安 |
|---|---|
| プラグイン 100〜300 個、プロジェクト 100 曲前後、内蔵 SSD のみ | **5〜10分** |
| ＋ 外付けドライブに音源ライブラリ（数百GB） | **10〜20分** |
| ＋ 外付け HDD が複数・プロジェクト数百曲 | **20〜40分** |
| `--quick` オプション（外付けドライブと容量計算を省略） | **2〜5分** |

画面に `[03:25] 探索中: …` のように経過時間が出るので、進み具合がわかります。1か所の探索は最大15分で自動的に打ち切ります（`--time-budget 秒数` で変更可）。

### 整理作業（人の手でやる部分）

| 作業 | 目安 |
|---|---|
| レポートを見て、使っていないもの・分類を確認 | 15〜30分 |
| Logic のプラグインマネージャでカテゴリ分け（下記） | 30〜60分（200個程度の場合） |
| インストーラーの整理（スクリプト実行） | 1分 |
| 未使用プラグインの退避（任意） | 10〜20分 |
| 音源ライブラリを外付けSSDへ移動（任意） | 1ライブラリあたり 5〜30分（容量次第） |

## 整理のしかた（おすすめ順）

### ① Logic の中を役割別に整理する（いちばん効果が大きく、安全）

プラグイン本体のファイルは、決まった場所（`/Library/Audio/Plug-Ins/Components` など）にないと Logic が読み込めません。
なので「フォルダ整理」は **Logic のプラグイン・マネージャ** で行うのが正しい方法です。

1. Logic Pro → **プラグイン・マネージャ** を開く
2. 左下の **＋** で、`logic_categories.md` に書いてあるカテゴリを作る（例：`01 ドラム・パーカッション`、`09 ボーカル`、`13 リバーブ`…）
3. 右のリストから、プラグインをカテゴリにドラッグ（⌘クリックで複数選択できます）
4. ついでに `00 未使用・お試し中` カテゴリも作ると、買ったのに使ってないものがひと目でわかります

これで、トラックにプラグインを挿すときのメニューが役割別に並びます。

### ② 散らばったインストーラーを1か所にまとめる

```bash
cd ~/Desktop/Logicプラグイン点検_XXXX
bash organize_installers.sh     # ミュージック/_プラグイン インストーラー保管庫/メーカー名 に移動
bash undo_installers.sh         # 元に戻したいとき
```

インストール済みのものは、基本的には削除しても大丈夫です（各メーカーのアカウントから再ダウンロードできます）。

### ③ 使っていないプラグインを退避する（任意）

`quarantine_plugins.sh` をテキストエディットで開き、退避したい行の先頭の `#` を消して保存 → `bash quarantine_plugins.sh`。

- **削除ではなく移動**（`Plug-Ins/_退避` フォルダへ）なので、`restore_plugins.sh` で戻せます
- Waves の WaveShell のように、1つのファイルに複数のプラグインが入っているもの（シェル）は、中に1つでも使用中のものがあれば対象外にしています
- Logic を終了してから実行してください

### ④ 音源ライブラリを外付けSSDにまとめる（Mac の容量が足りない場合）

Finder で直接動かすと音が鳴らなくなるので、**各メーカーのアプリの「場所を変更（Relocate）」機能**を使います。

- Native Instruments（Kontakt 音源）→ Native Access
- Spitfire Audio → Spitfire Audio アプリ
- Spectrasonics（Omnisphere / Keyscape / Trilian）→ STEAM フォルダを移動してエイリアスを置く（公式手順あり）
- Toontrack → Toontrack Product Manager
- EastWest → EW Installation Center

## よくある質問

**Q. 「未使用」になっているけど使ったことがある**
A. 判定は Logic プロジェクトの中身を調べています。MainStage・他の DAW・保存しなかったセッションでの使用はわかりません。また、プロジェクトを外付けドライブに置いている場合は、そのドライブをつないでから実行してください。

**Q. 分類が間違っている**
A. `category_overrides.csv` の「カテゴリ」列を書き換えて、次のように実行し直すと反映されます。

```bash
python3 plugin_audit.py --overrides ~/Desktop/Logicプラグイン点検_XXXX/category_overrides.csv
```

**Q. 時間がかかりすぎる**
A. `python3 plugin_audit.py --quick` で外付けドライブの探索と容量計算を省略できます。

### オプション一覧

```
--quick              外付けドライブを探さず、ライブラリ容量の計算も省略（速い）
--no-volumes         外付けドライブを探さない
--no-sizes           音源ライブラリの容量計算を省略
--time-budget 秒     1つの探索場所にかける最大時間（既定 900 秒）
--extra-projects パス  追加でプロジェクトを探すフォルダ
--overrides CSV      分類を手直しした category_overrides.csv を使う
--out フォルダ        出力先を指定
--no-open            終了後にレポートを自動で開かない
```

動作環境：macOS（Intel / Apple Silicon）、Python 3.8 以降（macOS 付属のもので OK・追加インストール不要）
